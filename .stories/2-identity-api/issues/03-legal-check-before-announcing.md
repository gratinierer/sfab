# Legal check before announcing the API

Label: ready-for-human

The API lets anyone store content anonymously and share access to it, and encrypted
content can't be inspected. Small operators can still have obligations for what they host.
Filed from review finding R22. This needs a lawyer's answer and the owner's decisions.
Deploying and testing don't depend on it, but announcing the API does.

## To settle

- Which jurisdiction applies, and what hosting obligations follow, including how abuse
  reports must be handled.
- Whether terms of use are needed, and how an agent with no human in the loop accepts them.
- Which contact address to publish in the API description's `info.contact`.

## Done when

- The answers are recorded in this file.
- The contact is published in `info.contact`.
- Any required changes are filed as issues.
